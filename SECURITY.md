# Security Policy

## Supported Versions

This template is provided as-is. Security fixes may be applied on a best-effort basis.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, send a private report to the maintainer with:

- A description of the issue
- Steps to reproduce
- Impact assessment (what an attacker can do)
- Any relevant logs or screenshots

If you fork this template, consider adding a real contact address or security email for your organization.
